# ollama-chat

本地 Ollama 对话页面，实时显示生成速度（tok/s）与运行状态。

## 为什么需要启动脚本

Ollama 的 CORS 只允许 `127.0.0.1` 来源的请求。直接双击 HTML 打开是 `file://` 协议，Origin 为 `null`，请求会被 403 拒绝。所以必须用一个只绑回环地址的本地静态服务器把页面端起来。

```bash
./启动对话页.command
```

默认端口 8777，默认用 Safari 打开。可在脚本顶部改 `PORT` 和 `BROWSER`。

## 功能

- 实时速度监控：输出 token、本轮实测、模型加载耗时、会话平均 / 峰值 / 累计
- 采样参数面板：`min_p`、`top_p`、`temperature` 等可调，改动会触发模型重载（界面有提示）
- 单次生成上限可控，`-1` 表示不限

## 依赖

本机需运行 Ollama，默认端点 `http://127.0.0.1:11434`。
